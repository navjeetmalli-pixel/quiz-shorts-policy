1. Who we are

Quiz Shorts Uploader ("the Application") is operated by Navjeet Singh Malli, an individual based in Victoria, Australia ("we", "us"). Contact: navjeetmalli@gmail.com.

2. What the Application is

The Application is a private tool that uploads quiz videos to our own YouTube channel (@quiz-shorts-x4r). It has exactly one user: the channel owner. It is not offered to the public and has no end users other than the owner.

3. Use of YouTube API Services

The Application uses YouTube API Services. By using the Application, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

4. Data the Application accesses

Through YouTube API Services the Application accesses only the owner's own data: channel ID and title, the IDs, titles, descriptions, tags, privacy status and upload status of videos it uploads, and the IDs and titles of the owner's playlists. It does not access any other user's data, comments, subscriptions, watch history, or analytics.

5. Data the Application stores

The Application stores, on the owner's own computer only: (a) an OAuth 2.0 refresh token in the macOS Keychain, used to authenticate to YouTube; (b) the IDs of videos it has uploaded and playlists it has created, in small local text files, so that it does not upload the same video twice. No YouTube data is stored on any server, shared with any third party, sold, or used for advertising. Stored data is not retained longer than needed and can be deleted at any time (see section 8).

6. Data the Application shares

None. The Application sends data only to YouTube (the video files and their metadata) and receives data only from YouTube. It uses no analytics, advertising or tracking services.

7. Cookies

The Application does not use cookies. This website does not set cookies.

8. Revoking access and deleting data

The owner can revoke the Application's access to their YouTube account at any time via the Google security settings page. Locally stored tokens and IDs can be deleted by removing the Keychain item and the local state files, which removes all data the Application holds.

9. Children

The Application is not directed at children and collects no personal information from anyone.

10. Changes

If this policy changes, the updated version will be published on this page with a new date.
